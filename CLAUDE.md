# Preferências do utilizador

- Sempre que fizeres um website, publica também uma pré-visualização como Artifact (claude.ai),
  além de entregar o código no repositório.
  Exceção: páginas que usam o nome, o logótipo ou a identidade de uma organização ou pessoa real
  (por exemplo, o site de um negócio existente) não podem ser publicadas como Artifact; nesse caso
  entrega os ficheiros e explica porquê.

# Sportovní centrum Semily · Atletická přípravka (redesign)

A complete visual and interaction redesign of
<https://www.sportovni-centrum.cz/krouzky/atleticka-pripravka>, plus the shared header,
navigation and footer, built as reusable patterns for the rest of the site.

**Scope, honestly stated:** only this page is rebuilt. Every other destination (navigation, related
programmes, news, contact, GDPR) links to the **original live URL**. No empty replacement routes
were created.

| | |
|---|---|
| Output | `dist/pages/krouzky-atleticka-pripravka.html`, served at the original URL `/krouzky/atleticka-pripravka` (rewrite rules in `deploy/apache-rewrite.conf`) |
| Stack | Static HTML generated by a small Node build (templates + build script ≈ 500 lines). Plain CSS, ~10 kB unminified vanilla JS, no runtime dependencies |
| Language | Czech (`lang="cs"`), self-hosted Archivo variable font subset to Latin + Latin Extended-A (all Czech letters) |
| Review copy | `preview/atleticka-pripravka-nahled.html`: one self-contained file with a permanent "Proposta de design · não é o site oficial / Návrh redesignu · nejde o oficiální web" banner. **Not for deployment.** |

## Commands

```sh
npm install                 # font package + axe-core (QA only)
npm run images              # source/originals → public/ + WebP/AVIF variants + content/images.json
sh scripts/subset_font.sh   # (only if the font changes) needs: pip install fonttools brotli
npm run sync-news           # REQUIRED before each build/deploy: copies the live "Novinky" list
npm run build               # → dist/
npm run serve               # http://localhost:4310/krouzky/atleticka-pripravka
npm run qa                  # Playwright + axe-core checks (expects a build; QA_PORT=<n> to pin the port)
BASE=/sub/ npm run build    # build for a sub-folder instead of the site root
node scripts/build-preview.mjs   # → preview/ (single-file review copy with banner)
```

## Design in brief

- **Direction: "the track".** The centre's identity (blue `#0081C1`, the logo, the template's
  green) is set against deep navy, white and a pale neutral. Thin running-lane curves, a straight
  turning into a bend, are the only decorative motif. They appear in the hero, the club call-to-action,
  the discipline tiles and the footer, and draw once as you arrive. No glass, gradients-as-decoration,
  neon or illustration style.
- **Logo** is the original 400×72 PNG at its original proportions. It is dark green on transparent,
  so it always sits on the white header.
- **Colour for text** uses accessible variants of the brand: `#0074AE` (5.1:1 on white) for links and
  buttons. `#0081C1` is kept for large type and graphics. The template greens (`#2FAA43`) are accents only,
  because they fail contrast as text.
- **Type:** Archivo (variable weight + width). Headlines are slightly condensed and heavy, for an athletic
  but not aggressive feel. Body text is 17→18 px, line height 1.65, left-aligned, max ~70 characters.
- **Page order:** written for a parent on a phone, who first needs to know who it is for, what it
  involves, where it happens and who to ask.
  1. **Hero:** H1, a one-sentence summary, the organiser statement (*Atletický klub Semily, z.s.*),
     a primary CTA to the club website and a secondary jump to *Jak probíhají tréninky*. Beside it is a
     stadium photo whose caption states that it is an illustrative venue photo, undated, and not of
     the programme.
  2. **Three facts:** Pro koho / Zaměření / Tréninky ("*Až* třikrát týdně", with "až" emphasised,
     never a fixed schedule). Static text, no counters.
  3. **O přípravce:** the original article text in full, an organiser card, and Běh / Skok / Hod
     pictograms (labels always visible).
  4. **Tréninky** (`#treninky`): two panels shown side by side. *Městský stadion* (with a link to the
     stadium page) and *Zimní období* (school gymnasiums; drawn graphic, because no photos of the
     gyms exist). The club call-to-action follows directly.
  5. **Fotografie:** the five original stadium photos in a 1 + 4 editorial grid, an accessible
     lightbox, and an explicit note that they show the venue and not the training.
  6. **Kroužky Sportovního centra:** all five programmes, with the current one marked (`aria-current`). This
     replaces the old sidebar.
  7. **Novinky:** the live list, titles only, no dates (the source shows none), plus *Všechny novinky*.
  8. **Footer:** reception contacts as working `tel:` / `mailto:` links. A page-specific note
     separates the club's responsibility from the centre's contacts. GDPR, Facebook, and the
     original logos (Sodexo, Edenred, Benefit Plus, Multisport, Město Semily) on the dark surface
     they were drawn for. They have no visible heading, as on the live site, so nothing claims what
     the cards pay for.
- **Motion:** a hero entrance (opacity + 16 px, staggered 70 ms, 620 ms; the photo fades in and
  settles from 1.04 scale), section reveals (18 px / 560 ms, once), 160–220 ms control and hover
  feedback, arrow nudges, image zoom 1.03 on hover, a one-time 900 ms lane drawing, and a header
  that gains a shadow and shrinks the logo slightly (a transform, so no layout shift). Smooth anchor
  scrolling uses `scroll-padding` for the sticky header. Under `prefers-reduced-motion` all movement
  and smooth scrolling are removed and everything is visible immediately. Printing always shows
  every section.
- **Resilience:** an inline boot script makes the menu buttons work from first paint. If `site.js`
  fails or is blocked, after 3 s only the motion class is removed, so hidden sections appear and
  the layout never changes (no late layout shift). Each feature in `site.js` is isolated, so an
  error in one cannot disable the others.
- **Navigation:** the original 7 top-level items and all 23 sub-items in their original order and
  columns (Sportoviště keeps its two columns, the shorter groups are one column). Desktop dropdowns
  open on hover (with intent delay), click or keyboard (a separate disclosure button next to each
  parent link). A click after hovering pins a dropdown open. Escape, click-outside and focus-leave
  close it, and focus is never dropped. The desktop/mobile breakpoint is in `em`, so visitors with
  larger default text get the mobile panel instead of a clipped menu.
  On mobile and tablet a full-height panel with expandable groups traps focus, makes the page
  behind it `inert`, closes on Escape or link choice, and returns focus to the toggle. Without JS,
  the menu is shown in full.
  *Rezervace sportoviště* stays in Sportoviště, labelled "externí rezervační systém". It is never
  presented as registration for athletics.

## Editing content (staff)

All words and links live in JSON. The templates contain only generic interface labels.

| File | What |
|---|---|
| `content/pages/atleticka-pripravka.json` | Everything on the page: hero, facts, overview, training panels, club CTA, gallery captions/alt text, related programmes, footer note, meta. `source` keeps the original article verbatim for reference. |
| `content/site.json` | Shared: logo, full navigation, contact data, Facebook, partner logos. |
| `content/news.json` | Written by `npm run sync-news` from the live Joomla module. Do not edit by hand. |
| `content/images.json` | Written by `npm run images` (dimensions and responsive variants). |

Rich-text fields accept only `<strong>`, `<em>`, `<a href="…">`, `<br>`. Everything else is escaped.

## Open items and unresolved details

1. **No photos of the programme exist** on the site. The athletics article has no images. The only
   athletics gallery is "02 - Atletické hry pro MŠ na městském stadioně v Semilech" (18.6.2013), a
   kindergarten event with identifiable small children. It was deliberately **not** embedded, so a
   2013 event is not presented as the current programme and children's photos are not reused out of
   context. The page links to the Fotogalerie instead. Photos of real sessions (with consent) would
   strengthen the page most.
2. **Stadium photos are undated.** A news item from 25 May 2026 announces construction of new
   changing rooms at the stadium, so the photos may not show its current state. Captions say "bez
   data pořízení". The originals are only 930×500 px, so the hero is sized not to upscale them much.
   Larger originals would help.
3. **No winter-gym photos.** The winter panel uses a drawn court graphic, and no school is named
   (the source names none).
4. **apple-touch-icon** on the live site is the stock Joomla! logo. A proper square icon should be
   made from the centre's vector logo. No vector or high-resolution logo is published.
5. **Analytics:** the live site loads legacy `ga.js` with a Universal Analytics ID (a product Google
   has shut down) and has no cookie consent. It was not ported. If statistics are wanted, use a
   consent-managed, current tool.
6. **`www.semily.cz`** (Město Semily partner link) could not be reached from the build environment
   on either http or https. It was kept exactly as on the live site and needs a check from a normal
   connection.
7. **Reservation system** `scsemily.fit.mefisto.cz` works only over plain `http` (https resets). It
   is kept as is; the operator should enable https.
8. **`www.sodexo.cz`** now redirects to the global `sodexo.com` (Sodexo's Czech benefits business has
   been renamed). The original destination is kept; the centre should confirm which card brand it
   still accepts and update the logo and link if needed.
9. **News is a build-time copy** of the live module. Run `npm run sync-news` before each deploy (the
   build warns if the copy is more than a day old). When integrated into Joomla, render the real
   module in this markup instead.
10. **Club details** (training days, times, ages, fees, registration, coaches) are intentionally
    absent: the source does not state them and the club owns them.
11. **Training venue vs. contact address.** The only address on the original page is the centre's
    (3. května 327). The stadium is a separate place, about 0.8 km away according to the stadium
    page's map. The page says the footer contacts belong to the centre and links to the stadium
    page. It does not print a stadium address the source does not give.
12. **Not used:** the athletics teaser image on the Kroužky overview page
    (`/media/widgetkit/atleticka-pripravka-….jpg`, 300×220). It appears to be a stock photo of
    identifiable children with no stated source or licence, and it is not part of this page.
13. **Source inconsistencies noticed (stadium page, outside this page's scope):** the "horní" vs
    "dolní" pitch, and the cinder pitch listed for rent while a 2026 news item calls it "bývalé".
    Worth correcting on the stadium page.

## Deployment notes

- **Joomla's `.htaccess` must stay in place.** The build writes no root `.htaccess`. Paste the two
  generated rules from `deploy/apache-rewrite.conf` into the existing `.htaccess`, after
  `RewriteEngine On` and **above** Joomla's SEF section. `/krouzky/atleticka-pripravka` is then
  served from `/pages/krouzky-atleticka-pripravka.html`, and the trailing-slash variant
  301-redirects.
- Copy `dist/` into the web root. It adds `/assets/` (with its own `.htaccess` that caches only the
  content-hashed CSS/JS) and `/pages/`. It adds WebP/AVIF files next to the originals in
  `/images/prolinacky/mestsky-stadion/`, and contains the original images at their existing paths
  (identical files). There is deliberately no physical `/krouzky/` folder, so Joomla keeps
  serving `/krouzky` and every other page.
- `BASE=/sub/folder/ npm run build` prefixes every asset URL and rewrite target for a sub-folder
  installation.
- To bring the design into Joomla itself, the templates map onto a template override
  (header/footer modules plus an article layout). `src/styles/site.css` and `src/js/site.js` work
  unchanged.

## Verification

`npm run qa` (Playwright Chromium + axe-core 4.10) passes **103 of 103** checks:

- **Responsive:** 320, 375, 414, 768, 1024, 1280 and 1920 px have no horizontal overflow, no
  clipped text, all targets are at least 24×24 px, body text is 17–18 px, and there are no
  console or network errors. With a 32 px browser default text size there is no overflow and the
  mobile panel starts at the header's real bottom edge.
- **Structure:** `lang="cs"`, the original `<title>`, canonical URL, one H1, no skipped heading
  levels, alt text and dimensions on every image, eager hero and lazy below-the-fold images,
  landmarks, no empty links, working in-page anchors, new-window links announced, and real
  `mailto:`/`tel:` links. Czech no-break spaces follow one-letter words and ordinals.
- **axe-core** WCAG 2.0/2.1/2.2 A + AA + best practice: 0 violations.
- **Keyboard and pointer (desktop):**
  - The skip link is the first stop and moves focus to the content.
  - Dropdowns open with Enter, Tab moves into them, and Escape closes them and returns focus.
  - They also open on hover and close on pointer-leave or an outside click. A click after
    hovering pins them open.
  - Hovering another item never takes a dropdown away from keyboard focus.
  - Every focus stop has a visible ring and is never under the sticky header.
- **Mobile menu:** focus moves inside, the current group is pre-expanded, groups expand on tap,
  all 30 links are present, focus is trapped, the page behind is inert, and Escape closes and
  returns focus. Rotating to desktop keeps focus, including when the toggle itself is focused.
- **Anchors:** "Jak probíhají tréninky" lands below the sticky header.
- **Lightbox:**
  - Opens by tap or Enter, with caption and alt text; arrows wrap around and a swipe advances.
  - Focus stays inside and returns to the photo on close.
  - The photo stays inside its frame and the controls are uncovered at 844×390, 320×215 (400 %
    zoom) and 1280×600.
  - Only the image format it displays is downloaded and preloaded.
- **Print:** every section is visible without scrolling first.
- **Resilience:**
  - Reduced motion: everything is visible, with no movement and no smooth scrolling.
  - JavaScript off (phone and desktop): all content is visible, all 30 navigation links are
    reachable by Tab, and dropdowns open on hover.
  - `site.js` blocked: the boot menu works (modal panel on phones; dropdowns close with Escape or
    an outside click) and all content appears after 3 s.
  - `site.js` 4 s late: layout shift 0. A menu opened before it arrives is taken over correctly.
  - Navigation set-up error (injected): the menu keeps working.
- **Page weight** (uncompressed, measured locally): about 380 KB on a phone (8 requests) and about
  400 KB on desktop (12 requests), with layout shift 0.

**Independent review.**
1. Five reviewers (content fidelity, accessibility, visual design, motion and performance,
   engineering) each reviewed the build, and every finding was checked by a skeptical verifier:
   33 were confirmed and 17 rejected.
2. All 33 were fixed. A second round re-tested every one against the new build with its own
   Playwright scripts: 23 were fully fixed, and the 10 partial fixes plus 12 small regressions
   it found were then fixed too.
3. Every browser-facing item now has a regression check in `scripts/qa.mjs`. The rest (news
   sync, image script, `BASE` and content validation) fail loudly with a clear message.

Not automated: pinch-zoom inside the lightbox (the stage allows `pinch-zoom`, and swipes are
ignored while zoomed in). The reviewers checked it through the DevTools touch protocol, but it is
worth a quick try on a real phone.

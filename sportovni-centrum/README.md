# Sportovní centrum Semily · Atletická přípravka (redesign)

A complete visual and interaction redesign of
<https://www.sportovni-centrum.cz/krouzky/atleticka-pripravka>, plus the shared header,
navigation and footer, built as reusable patterns for the rest of the site.

**Scope, honestly stated:** only this page is rebuilt. Every other destination (navigation, related
programmes, news, contact, GDPR) links to the **original live URL**. No empty replacement routes
were created.

| | |
|---|---|
| Output | `dist/krouzky/atleticka-pripravka/index.html`, served at the original URL `/krouzky/atleticka-pripravka` |
| Stack | Static HTML generated by a small Node build (templates + build script ≈ 500 lines). Plain CSS, ~10 kB unminified vanilla JS, no runtime dependencies |
| Language | Czech (`lang="cs"`), self-hosted Archivo variable font subset to Latin + Latin Extended-A (all Czech letters) |
| Review copy | `preview/atleticka-pripravka-nahled.html`: one self-contained file with a permanent "Proposta de design · não é o site oficial / Návrh redesignu · nejde o oficiální web" banner. **Not for deployment.** |

## Commands

```sh
npm install                 # font package + axe-core (QA only)
npm run images              # source/originals → public/ + WebP/AVIF variants + content/images.json
sh scripts/subset_font.sh   # (only if the font changes) needs: pip install fonttools brotli
npm run sync-news           # REQUIRED before each build/deploy: copies the live "Novinky" list
npm run build               # → dist/
npm run serve               # http://localhost:4310/krouzky/atleticka-pripravka
npm run qa                  # Playwright + axe-core checks (expects a build)
node scripts/build-preview.mjs   # → preview/ (single-file review copy with banner)
```

## Design in brief

- **Direction: "the track".** The centre's identity (blue `#0081C1`, the logo, the template's
  green) is set against deep navy, white and a pale neutral. Thin running-lane curves, a straight
  turning into a bend, are the only decorative motif. They appear in the hero, the club call-to-action,
  the discipline tiles and the footer, and draw once as you arrive. No glass, gradients-as-decoration,
  neon or illustration style.
- **Logo** is the original 400×72 PNG at its original proportions. It is dark green on transparent,
  so it always sits on the white header.
- **Colour for text** uses accessible variants of the brand: `#0074AE` (5.1:1 on white) for links and
  buttons. `#0081C1` is kept for large type and graphics. The template greens (`#2FAA43`) are accents only,
  because they fail contrast as text.
- **Type:** Archivo (variable weight + width). Headlines are slightly condensed and heavy, for an athletic
  but not aggressive feel. Body text is 17→18 px, line height 1.65, left-aligned, max ~70 characters.
- **Page order:** written for a parent on a phone, who first needs to know who it is for, what it
  involves, where it happens and who to ask.
  1. **Hero:** H1, a one-sentence summary, the organiser statement (*Atletický klub Semily, z.s.*),
     a primary CTA to the club website and a secondary jump to *Jak probíhají tréninky*. Beside it is a
     stadium photo whose caption states that it is an illustrative venue photo, undated, and not of
     the programme.
  2. **Three facts:** Pro koho / Zaměření / Tréninky ("*Až* třikrát týdně", with "až" emphasised,
     never a fixed schedule). Static text, no counters.
  3. **O přípravce:** the original article text in full, an organiser card, and Běh / Skok / Hod
     pictograms (labels always visible).
  4. **Tréninky** (`#treninky`): two panels shown side by side. *Městský stadion* (with a link to the
     stadium page) and *Zimní období* (school gymnasiums; drawn graphic, because no photos of the
     gyms exist). The club call-to-action follows directly.
  5. **Fotografie:** the five original stadium photos in a 1 + 4 editorial grid, an accessible
     lightbox, and an explicit note that they show the venue and not the training.
  6. **Další kroužky:** all five programmes, with the current one marked (`aria-current`). This
     replaces the old sidebar.
  7. **Novinky:** the live list, titles only, no dates (the source shows none), plus *Všechny novinky*.
  8. **Footer:** reception contacts as working `tel:` / `mailto:` links. A page-specific note
     separates the club's responsibility from the reception. GDPR, Facebook, and the original
     partner logos on the dark surface they were drawn for.
- **Motion:** a hero entrance (opacity + 16 px, staggered 70 ms, about 600 ms), section reveals
  (18 px / 560 ms, once), 160–200 ms control feedback, arrow nudges, image zoom 1.03 on hover, a
  one-time lane drawing, and a header that gains a shadow and shrinks the logo slightly (a transform,
  so no layout shift). Smooth anchor scrolling uses `scroll-padding` for the sticky header. Under
  `prefers-reduced-motion` all movement and smooth scrolling are removed and everything is visible
  immediately. If the script fails or is blocked, a 3-second failsafe reverts to the no-JS layout,
  so nothing stays hidden.
- **Navigation:** the original 7 top-level items and all 23 sub-items in their original order and
  columns. Desktop dropdowns open on hover (with intent delay), click or keyboard (a separate
  disclosure button next to each parent link). Escape, click-outside and focus-leave close them.
  On mobile and tablet a full-height panel with expandable groups traps focus, closes on Escape
  or link choice, and returns focus to the toggle. Without JS, the menu is shown in full.
  *Rezervace sportoviště* stays in Sportoviště, labelled "externí rezervační systém". It is never
  presented as registration for athletics.

## Editing content (staff)

All words and links live in JSON. The templates contain only generic interface labels.

| File | What |
|---|---|
| `content/pages/atleticka-pripravka.json` | Everything on the page: hero, facts, overview, training panels, club CTA, gallery captions/alt text, related programmes, footer note, meta. `source` keeps the original article verbatim for reference. |
| `content/site.json` | Shared: logo, full navigation, contact data, Facebook, partner logos. |
| `content/news.json` | Written by `npm run sync-news` from the live Joomla module. Do not edit by hand. |
| `content/images.json` | Written by `npm run images` (dimensions and responsive variants). |

Rich-text fields accept only `<strong>`, `<em>`, `<a href="…">`, `<br>`. Everything else is escaped.

## Open items and unresolved details

1. **No photos of the programme exist** on the site. The athletics article has no images. The only
   athletics gallery is "02 - Atletické hry pro MŠ na městském stadioně v Semilech" (18.6.2013), a
   kindergarten event with identifiable small children. It was deliberately **not** embedded, so a
   2013 event is not presented as the current programme and children's photos are not reused out of
   context. The page links to the Fotogalerie instead. Photos of real sessions (with consent) would
   strengthen the page most.
2. **Stadium photos are undated.** A news item from 25 May 2026 announces construction of new
   changing rooms at the stadium, so the photos may not show its current state. Captions say "bez
   data pořízení". The originals are only 930×500 px, so the hero is sized not to upscale them much.
   Larger originals would help.
3. **No winter-gym photos.** The winter panel uses a drawn court graphic, and no school is named
   (the source names none).
4. **apple-touch-icon** on the live site is the stock Joomla! logo. A proper square icon should be
   made from the centre's vector logo. No vector or high-resolution logo is published.
5. **Analytics:** the live site loads legacy `ga.js` with a Universal Analytics ID (a product Google
   has shut down) and has no cookie consent. It was not ported. If statistics are wanted, use a
   consent-managed, current tool.
6. **`www.semily.cz`** (Město Semily partner link) could not be reached from the build environment
   on either http or https. It was kept exactly as on the live site and needs a check from a normal
   connection.
7. **Reservation system** `scsemily.fit.mefisto.cz` works only over plain `http` (https resets). It
   is kept as is; the operator should enable https.
8. **`www.sodexo.cz`** now redirects to the global `sodexo.com` (Sodexo's Czech benefits business has
   been renamed). The original destination is kept; the centre should confirm which card brand it
   still accepts and update the logo and link if needed.
9. **News is a build-time copy** of the live module. Run `npm run sync-news` before each deploy (the
   build warns if the copy is more than a day old). When integrated into Joomla, render the real
   module in this markup instead.
10. **Club details** (training days, times, ages, fees, registration, coaches) are intentionally
    absent: the source does not state them and the club owns them.

## Deployment notes

- `dist/` keeps the original URL. `dist/.htaccess` (Apache) serves `/krouzky/atleticka-pripravka`
  without a trailing slash and 301-redirects the slash variant. Content-hashed CSS/JS files are
  cached as immutable.
- Original image paths (`/images/…`, `/templates/yoo_infinite/favicon.ico`) are unchanged, so the
  build can sit next to the Joomla installation. To bring the design into Joomla itself, the
  templates map onto a template override (header/footer modules plus an article layout), and
  `src/styles/site.css` and `src/js/site.js` work unchanged.
